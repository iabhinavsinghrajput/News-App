## 📰 News App

A simple news application built using HTML, CSS, and JavaScript that allows users to view the latest top headlines from the US using NewsAPI.

## 🚀 Live Features
- Fetches and displays the latest news headlines
- News cards show image, title, description, and Read More link
- Responsive layout using CSS Grid
- Handles API errors gracefully

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- NewsAPI

## 📂 Project Structure
- news-app/
  - index.html
  - style.css
  - script.js
  - README.md

## ⚙️ How It Works
- User clicks the **Load Latest News** button
- JavaScript sends a request to NewsAPI to fetch top headlines
- Dynamically creates news cards showing:
  - Image (or placeholder if missing)
  - Title
  - Short description
  - Link to full article
